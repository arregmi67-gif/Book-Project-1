Web Technology-I

The internet is a vast network of computers, and to access the information available on it, we use specific software. These are primarily web browsers and search engines.

Web Browser

:

A web browser is an application software that allows users to access, retrieve, and view information and content on the World Wide Web (WWW). It acts as an interface between the user and the web server. When you type a website address (URL) or click a link, the browser sends a request to the web server, which then sends back the requested web page. The browser interprets the code (like HTML, CSS, JavaScript) and displays the content in a human-readable format.

Common Web Browsers:

Google Chrome
Mozilla Firefox
Microsoft Edge
Apple Safari
Opera

Search Engine

:

A search engine is a web-based tool that enables users to locate information on the World Wide Web. Its main purpose is to search for information on the internet. Search engines are software programs that search for websites based on keywords typed in by the user. They go through their database of information to locate the information you are looking for.

How a Search Engine Works:
Crawling: Search engine bots (also called spiders or crawlers) systematically browse the web, discovering new and updated web pages.
Indexing: The information gathered by crawlers is then processed and stored in a massive database, creating an index. This index is like a giant library catalog.
Searching: When a user enters a query, the search engine quickly searches its index for relevant pages and ranks them based on various algorithms to provide the most accurate results.

Popular Search Engines:
Google
Bing
Yahoo!
DuckDuckGo

Overview of Internet and Web Technology

Internet

:

The Internet is a global system of interconnected computer networks that uses the Internet protocol suite (TCP/IP) to link billions of devices worldwide. It is a "network of networks" that consists of private, public, academic, business, and government networks of local to global scope, linked by a broad array of electronic, wireless, and optical networking technologies. Key Concepts of the Internet:

World Wide Web (WWW): Often confused with the internet, the WWW is a system of interconnected hypertext documents and other web resources that are accessed via the internet. It's an application built on top of the internet.
Client-Server Model: The internet primarily operates on a client-server model. A client (your web browser) requests information or services from a server (a powerful computer hosting websites).
Protocols: These are rules that govern how data is transmitted over the internet. Examples include HTTP (Hypertext Transfer Protocol), HTTPS (Secure HTTP), FTP (File Transfer Protocol), and TCP/IP (Transmission Control Protocol/Internet Protocol).
IP Address: A unique numerical label assigned to each device connected to a computer network that uses the Internet Protocol for communication.
Domain Name System (DNS): A hierarchical and decentralized naming system for computers, services, or other resources connected to the Internet or a private network. It translates human-readable domain names (like google.com) into IP addresses.
Web Technology: Web technology broadly refers to the tasks associated with developing websites for hosting via the internet or intranet. It encompasses the various tools, languages, and protocols used to create and maintain websites and web applications. This can range from developing static pages to complex web-based applications like e-commerce or social network websites.

Content Management System (CMS)

A Content Management System (CMS) is an application that allows users to create, manage, and modify content on a website without the need for specialized technical knowledge or coding skills. It simplifies the process of web content creation, workflow management, and publishing. Key Features of a CMS:

User-friendly Interface: Often provides a graphical user interface (GUI) with text editors similar to word processors.
Content Creation and Editing: Tools to easily add, edit, and format text, images, videos, and other media.
Workflow Management: Allows multiple users to collaborate, with roles and permissions (e.g., author, editor, publisher).
Design Templates: Offers pre-designed templates or themes to quickly change the look and feel of a website without altering the content.
SEO Tools: Built-in features to help optimize website content for search engines.
Scalability: Can manage small personal blogs to large corporate websites.
Examples of Popular CMS:

WordPress
Joomla!
Drupal
Wix
Shopify
Introduction to HTML (Objectives, Structure, Tags, Attributes)

HTML (Hypertext Markup Language):

HTML is the standard markup language for creating web pages. It provides the basic structure of a web page, defining its content and layout. Without HTML, the World Wide Web would not exist.

Objectives of HTML:

To define the structure of web content.
To enable embedding text, images, multimedia, and other links or documents.
To provide a means to prepare a structured document by using paragraphs, formatting, links, and lists.
To allow web browsers to display the content of a web page.
To serve as the foundation upon which other web technologies like CSS and JavaScript are built.
